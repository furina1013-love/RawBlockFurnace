# Raw Block Furnace（粗矿块熔炉）

把**粗矿块**直接熔成对应的**金属块**。

原版没有这种配方（只有「粗矿物品 → 锭」），本模组补上：粗铁块→铁块、粗铜块→铜块、粗金块→金块，
一律 200 tick。

**兼容其它模组**：Mekanism、Immersive Engineering、AllTheOres、Thermal 等模组的粗矿块会在运行时按注册名自动识别配对，无需配置。

**兼容压缩方块**：装了 AllTheCompressed 后，压缩粗矿块（1x–9x）会熔成对应的压缩成品块，经验随等级放大（1x = 单块经验 × 9）。

全部是原版熔炉配方，JEI / EMI 可查。支持 1.21.1 NeoForge（21.1.248+）与 1.20.1 Forge 47.x。
